# 性能测试用例设计标准

基于性能需求 / SLA 指标生成性能测试用例时，遵循以下标准。

## 覆盖维度

对每个性能场景，至少覆盖：

1. **基准测试**：单用户响应时间、吞吐量基线
2. **负载测试**：逐步加压至预期并发，观察吞吐量与响应时间拐点
3. **压力测试**：超过预期负载，验证降级与恢复行为
4. **稳定性测试**：持续运行，观察内存泄漏、连接池耗尽
5. **峰值测试**：突发流量，验证弹性扩缩容

## 字段要求

每条用例必须包含：

- **用例标识**：`PERF-[场景]-[序号]`（如 `PERF-LOGIN-001`）
- **场景名称**：描述测试场景
- **用例类型**：基准 / 负载 / 压力 / 稳定性 / 峰值
- **优先级**：P0（核心接口）/ P1（重要接口）/ P2（次要接口）
- **前置条件**：测试数据量、环境配置
- **负载模型**：并发用户数、RPS 目标、持续时长
- **性能指标**：响应时间 P95/P99、错误率、吞吐量
- **通过标准**：SLO 达标、错误率 < 阈值

## 输出格式示例

```markdown
## [P0] 登录接口负载测试
[测试类型] 负载
[前置条件] 1000 个测试用户已创建
[负载模型] 50 并发，持续 10 分钟，逐步加压
[性能指标] 响应时间 P95 < 500ms，错误率 < 1%
[通过标准] 吞吐量 >= 100 RPS，无 5xx 错误
```
