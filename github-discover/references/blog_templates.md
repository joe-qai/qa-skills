# Blog 文章模板参考

本文档存放公众号/知乎风格的长文模板和写作规范。Agent 在生成文章时参考这些结构。

---

## 公众号文章结构

```
# [标题]：{项目名} 凭什么火了？

*{日期} · 每日开源项目深挖*

[钩子段落：一句话抓住注意力，带数字或反常识观点]

## 🔧 技术栈拆解
[核心依赖表格 + 简短评述]

## 📁 项目结构
[目录树 ASCII 图]

## 💡 值不值得看？
[信号点列表 + 结论]

> 📌 原文链接：{URL}

---
*这是 github-discover 每日开源项目深挖系列的第 N 篇。*
```

## 网感写作技巧

### 钩子句式

- "最近刷到这个项目的时候我愣了一下——"
- "说实话，一开始我没太在意，直到我看到..."
- "{N} star 的项目，凭什么让我眼前一亮？"
- "这个仓库，把 {某技术} 玩出了新花样"
- "如果你正在做 {某方向}，这个项目值得你停下来看一下"

### 避免的写法

- ❌ "本项目是一个基于 xxx 的 yyy 系统"（太官方）
- ❌ 大量堆砌技术名词没有观点
- ❌ 平铺直叙没有情绪起伏
- ❌ 结尾没有明确的行动号召（star / clone / 关注）

### 可以加的 emoji

| 用途 | emoji |
|------|-------|
| 星标/热度 | ⭐ 🔥 |
| 技术栈 | 🔧 🛠️ 💻 |
| 结构/文件 | 📁 📂 |
| 结论/推荐 | 💡 ✅ ⚡ |
| 链接 | 🔗 📌 |
| 时间/更新 | 📅 🔄 |

## 配图规范

卡片图规格：800×520 PNG

内容包含：
- 项目名称（大号字体居中）
- Star 数徽章
- 语言标签
- 描述（一行）
- 技术栈色条（top 8 依赖）
- 底部品牌标识
